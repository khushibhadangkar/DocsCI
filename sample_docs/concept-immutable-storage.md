# Immutable storage concepts

Immutable storage prevents deletion or alteration of recovery points.

## How it works

When enabled, immutable storage enforces strict retention holds on target buckets.
Administrators generate an access token to authorize lock duration modifications.
This architecture guarantees ransomware protection across every repository in your enterprise.

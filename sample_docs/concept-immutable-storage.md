# Immutable Storage Concepts

Immutable storage prevents deletion or alteration of recovery points.

## How it works

When enabled, a worm storage bucket enforces strict retention holds.
Security tokens can be generated by administrators to authorize lock duration changes.
This architecture guarantees ransomware protection across every storage pool in your enterprise.

# Understanding Recovery Points and RPO

Recovery points define the state of application data at a specific moment in time.

## RPO targets

An RPO target establishes the maximum acceptable data loss interval during unplanned downtime.
Point-in-time copies are generated by the agent every fifteen minutes for mission-critical databases.
Basically, shorter intervals minimize potential data loss during unexpected fail-over scenarios.

# Restore a Single File from Storage

Users can recover individual files without full system restores.

## Recovery steps

Follow these steps to recover lost files:
1. Open the CloudVault Web Console.
2. The user must browse to the target snapshot.
3. Select the file and click Restore.

Refer to the [missing disaster guide](disaster-guide-missing.md) for more details.
